# Erp-software-architecture-SalonFlow ERP
 

Este repositorio contiene la documentación y modelos de arquitectura del sistema **SalonFlow ERP**, desarrollado como parte del taller de arquitectura de software.  
El objetivo es centralizar procesos operativos de pequeñas peluquerías y barberías en una sola plataforma web.

## Objetivo del taller

- Aplicar principios de **arquitectura por capas**.  
- Documentar vistas de contexto, bloques, ejecución y despliegue.  
- Usar **PlantUML** para generar diagramas.  
- Mantener la documentación organizada y fácil de navegar.
